# Industrial Brutalism & Tactical Telemetry UI

Swiss typographic systems meets military terminal aesthetics. Data-dense, mechanically precise interfaces.

## Core Visual Paradigms

### Swiss Industrial Print (Light Mode)
- High-contrast light substrates
- Monolithic sans-serifs at massive scale
- Aggressive asymmetry
- Primary red accents only
- Derived from 1960s corporate identity and machinery blueprints

### Tactical Telemetry / CRT Terminal (Dark Mode)
- Dark mode only
- Monospaced typography throughout
- Tabular data density
- Simulated hardware limitations (phosphor glow, scanlines)

## Typography

**Macro (headings):**
- Neo-grotesque heavy sans-serifs (Bebas Neue, Space Grotesk Heavy, Neue Haas Grotesk)
- Massive scale — headlines 80px–200px
- Tracking: −0.03em to −0.06em (extremely tight)
- Leading: 0.85–0.95
- ALWAYS uppercase

**Micro (data/labels):**
- Fixed-scale monospace (IBM Plex Mono, JetBrains Mono)
- 10–14px
- Letter-spacing: 0.05–0.1em
- Uniformly uppercase

## Color Architecture

**Light Mode:**
- Background: Off-white #F4F4F0
- Foreground: Carbon ink #050505
- Accent: Aviation red #E61919 (only accent)

**Dark Mode:**
- Background: Deactivated CRT #0A0A0A
- Foreground: White phosphor #EAEAEA
- Accent: Same red #E61919
- Terminal green #4AF626 used for single semantic purpose only

## Spatial Engineering

- CSS Grid with mathematically engineered proportions
- Visible compartmentalization through solid borders
- Oscillation between extreme density and negative space
- **Absolute rejection of rounded corners**
- No gradients, no shadows, no blur effects

## Technical Execution

- ASCII framing: `[ ]`, `< >`, `|`, `—`
- Industrial symbols: ®, ©, ™, △, ▲
- CRT scanlines: repeating-gradient overlay
- Halftone degradation: SVG filters
- Semantic HTML: `<samp>`, `<kbd>`, `<output>` for telemetry data

## When to Use This Skill

Apply for: developer tools, monitoring dashboards, system status pages, technical documentation, experimental/art sites, portfolio for designers/engineers wanting to stand out.

Note: This is a strong aesthetic — confirm with context before applying. Not suitable for consumer-facing products targeting general audiences.
